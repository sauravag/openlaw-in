# OpenLaw.in Retrieval and Answer Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retrieve grounded context and produce answers in which **every citation resolves to a chunk retrieved in that same turn** — enforced structurally, not by prompting.

**Architecture:** Hybrid retrieval (voyage-4 dense + the published sparse BM25 vectors) against Qdrant, expanded by bounded graph traversal, then reranked. The generator returns **structured JSON** — a list of claims, each carrying the `chunk_id`s that support it — rather than prose with inline citations. A deterministic validator then performs set-membership checking with no LLM call: any claim referencing a chunk outside this turn's retrieval set is dropped and logged. Weak retrieval produces an explicit refusal routed to legal aid, never a guess.

**Tech Stack:** Python 3.12+, `anthropic` SDK, `voyageai`, `qdrant-client`, `neo4j`, pydantic, pytest.

**Spec:** `docs/superpowers/specs/2026-09-08-openlaw-in-design.md` (§6, §8)

**Depends on:**
- `2026-09-08-corpus-foundation.md` — Tasks 1, 10, 11, 12 (config, `acts_india`, `sc_judgments_v1`, validation)
- `2026-09-08-knowledge-graph.md` — Tasks 1, 7 (`graph_driver`, `expand_chunks`)

## Global Constraints

- **The answer contract:** every `chunk_id` a claim cites must be a member of the retrieval set for that turn. Violations are dropped, never rendered.
- **Validation happens in English, before any translation.** Keeping the safety-critical step monolingual is why translation (Plan 4) cannot introduce an unverified citation.
- **Every rendered citation carries a government source URL** taken from the chunk payload, never generated by the model.
- **Retrieval MUST exclude provisions without a resolvable `source_url`.** 17% of restored
  `acts_india` points (~187,000, all `jurisdiction: regulatory`) carry an empty or non-URL
  `source_url`. `chunk_from_point` already returns `None` for these, which is the enforcement
  point — do not weaken it. Prefer also filtering server-side in the Qdrant query so they
  never occupy a retrieval slot.
- **Query embeddings MUST be voyage-4 with `input_type="query"`.** Document vectors used `input_type="document"`; mixing the two measurably degrades retrieval.
- **Default generator model is `claude-opus-5`** with `thinking: {"type": "adaptive"}`. Models resolve per role — never hard-code a model at a call site.
- **Server-side refusal fallbacks are enabled** on Opus 5 (`betas: ["server-side-fallback-2026-07-01"]`, `fallbacks: "default"`), and `stop_reason == "refusal"` is handled before reading content.
- **Prompt caching:** stable system prompt before the cache breakpoint, per-turn retrieved chunks after it. Caching retrieved context would yield a 0% hit rate.
- **No assistant prefill** — it returns a 400 on current models. Shape is controlled by the output schema instead.
- **Structured outputs use `output_config={"format": ...}`**, not the deprecated `output_format`.
- **Python style:** type hints everywhere, `pathlib.Path`, f-strings, functions under 50 lines, files under 800 lines.
- **Immutability:** pipeline stages return new objects.
- **TDD mandatory**, minimum 80% coverage. No unit test may call a live LLM — the generator sits behind a Protocol and is stubbed.

```python
"""Query embedding.

The corpus was embedded with voyage-4 using `input_type="document"`. Queries must
use the same model but `input_type="query"` — Voyage applies different prefixes to
each side, and mixing them measurably degrades retrieval.
"""

import hashlib
from typing import Protocol

from openlaw.index.embed import EMBEDDING_DIMENSIONS, EMBEDDING_MODEL

QUERY_INPUT_TYPE = "query"


class QueryEmbedder(Protocol):
    """Anything that can turn a user query into a vector."""

    def embed_query(self, text: str) -> list[float]:
        """Return the query vector for `text`."""
        ...


class VoyageQueryEmbedder:
    """A `QueryEmbedder` backed by the Voyage AI API."""

    def __init__(self, api_key: str, model: str = EMBEDDING_MODEL) -> None:
        import voyageai

        self._client = voyageai.Client(api_key=api_key)
        self._model = model

    def embed_query(self, text: str) -> list[float]:
        """Embed `text` as a query, returning a single vector."""
        if not text or not text.strip():
            raise ValueError("cannot embed an empty query")
        result = self._client.embed(
            [text], model=self._model, input_type=QUERY_INPUT_TYPE
        )
        return result.embeddings[0]


class StubQueryEmbedder:
    """A deterministic `QueryEmbedder` for tests — no network, no API key.

    Derives a stable pseudo-vector from the SHA-256 of the text, so equal inputs
    give equal vectors and different inputs differ.
    """

    def __init__(self, vector: list[float] | None = None) -> None:
        self._fixed = vector

    def embed_query(self, text: str) -> list[float]:
        """Return a deterministic vector of the corpus dimensionality."""
        if not text or not text.strip():
            raise ValueError("cannot embed an empty query")
        if self._fixed is not None:
            return list(self._fixed)

        digest = hashlib.sha256(text.strip().encode("utf-8")).digest()
        return [
            digest[index % len(digest)] / 255.0
            for index in range(EMBEDDING_DIMENSIONS)
        ]
```

```python
"""The retrieval context — the set of chunks a turn is allowed to cite.

`RetrievalContext.chunk_ids` is the authority the citation validator checks
against. A chunk cannot enter the context without a government source URL, so
anything the model is permitted to cite is provably attributable.
"""

from enum import Enum

from pydantic import BaseModel, ConfigDict, Field


class ChunkKind(Enum):
    """What kind of legal material a chunk holds."""

    PROVISION = "provision"
    JUDGMENT = "judgment"


class RetrievedChunk(BaseModel):
    """One retrieved chunk, with everything needed to render a citation."""

    model_config = ConfigDict(frozen=True)

    chunk_id: str = Field(min_length=1)
    text: str = Field(min_length=1)
    source_url: str = Field(min_length=1)
    score: float
    kind: ChunkKind
    title: str | None = None
    court_code: str | None = None
    decision_date: str | None = None
    headnote: str | None = None


class RetrievalContext(BaseModel):
    """Everything retrieved for one turn."""

    model_config = ConfigDict(frozen=True)

    query: str
    chunks: tuple[RetrievedChunk, ...] = ()

    @property
    def chunk_ids(self) -> frozenset[str]:
        """The set of chunk ids a claim may legitimately cite this turn."""
        return frozenset(chunk.chunk_id for chunk in self.chunks)

    def by_id(self, chunk_id: str) -> RetrievedChunk | None:
        """Return the chunk with `chunk_id`, or None when it was not retrieved."""
        for chunk in self.chunks:
            if chunk.chunk_id == chunk_id:
                return chunk
        return None
```

```python
"""Hybrid dense + sparse search against Qdrant.

The published collections carry a named sparse vector for BM25 alongside the
dense voyage-4 vector. Querying both and fusing with reciprocal rank fusion
recovers exact statutory references that pure dense retrieval misses — a citizen
asking about "Section 138" needs the lexical match.
"""

from typing import Any

import httpx
from pydantic import ValidationError

from openlaw.index.qdrant_restore import ACTS_INDIA
from openlaw.index.upsert import SC_COLLECTION
from openlaw.retrieval.context import ChunkKind, RetrievedChunk

SEARCH_COLLECTIONS: tuple[str, ...] = (ACTS_INDIA.name, SC_COLLECTION)
PREFETCH_MULTIPLIER = 4


def build_hybrid_request(
    vector: list[float], limit: int, court_codes: tuple[str, ...] | None
) -> dict[str, Any]:
    """Return the Qdrant query body fusing dense and sparse retrieval."""
    prefetch_limit = limit * PREFETCH_MULTIPLIER
    request: dict[str, Any] = {
        "prefetch": [
            {"query": vector, "using": "dense", "limit": prefetch_limit},
            {"query": vector, "using": "sparse", "limit": prefetch_limit},
        ],
        "query": {"fusion": "rrf"},
        "limit": limit,
        "with_payload": True,
        "with_vector": False,
    }
    if court_codes:
        request["filter"] = {
            "must": [{"key": "court_code", "match": {"any": list(court_codes)}}]
        }
    return request


def chunk_from_point(point: dict[str, Any]) -> RetrievedChunk | None:
    """Map a Qdrant point to a `RetrievedChunk`, or None when it is unusable."""
    payload = point.get("payload") or {}
    kind = ChunkKind.JUDGMENT if payload.get("case_id") else ChunkKind.PROVISION
    try:
        return RetrievedChunk(
            chunk_id=str(payload.get("chunk_id") or ""),
            text=str(payload.get("text") or ""),
            source_url=str(payload.get("source_url") or ""),
            score=float(point.get("score") or 0.0),
            kind=kind,
            title=payload.get("title"),
            court_code=payload.get("court_code"),
            decision_date=payload.get("decision_date"),
            headnote=payload.get("headnote"),
        )
    except ValidationError:
        return None


def search(
    client: httpx.Client,
    qdrant_url: str,
    vector: list[float],
    limit: int = 10,
    court_codes: tuple[str, ...] | None = None,
) -> tuple[RetrievedChunk, ...]:
    """Search every corpus collection and return the merged, score-ordered hits."""
    request = build_hybrid_request(vector, limit, court_codes)
    chunks: list[RetrievedChunk] = []

    for collection in SEARCH_COLLECTIONS:
        response = client.post(
            f"{qdrant_url}/collections/{collection}/points/query",
            json=request,
            timeout=30,
        )
        response.raise_for_status()
        for point in response.json()["result"]["points"]:
            chunk = chunk_from_point(point)
            if chunk is not None:
                chunks.append(chunk)

    chunks.sort(key=lambda chunk: chunk.score, reverse=True)
    return tuple(chunks[:limit])
```

```python
"""Merging graph-expanded chunks and reranking the result.

`ScoreReranker` is the v1 default — plain score ordering. `AuthorityReranker`
blends retrieval score with the PageRank authority precomputed by the knowledge
graph, so a landmark precedent can outrank a marginally closer obscure one. Which
reranker runs is a configuration decision, not a code change.
"""

from typing import Protocol

from openlaw.retrieval.context import RetrievedChunk


def merge_chunks(
    primary: tuple[RetrievedChunk, ...], expanded: tuple[RetrievedChunk, ...]
) -> tuple[RetrievedChunk, ...]:
    """Merge graph-expanded chunks into directly retrieved ones.

    Deduplicates by `chunk_id`; the primary chunk wins a collision so graph
    expansion can never overwrite a directly retrieved chunk's score.
    """
    seen: set[str] = {chunk.chunk_id for chunk in primary}
    merged = list(primary)
    for chunk in expanded:
        if chunk.chunk_id in seen:
            continue
        seen.add(chunk.chunk_id)
        merged.append(chunk)
    return tuple(merged)


class Reranker(Protocol):
    """Anything that can reorder retrieved chunks for a query."""

    def rerank(
        self, query: str, chunks: tuple[RetrievedChunk, ...]
    ) -> tuple[RetrievedChunk, ...]:
        """Return `chunks` reordered by relevance to `query`."""
        ...


class ScoreReranker:
    """Orders purely by retrieval score. The v1 default."""

    def rerank(
        self, query: str, chunks: tuple[RetrievedChunk, ...]
    ) -> tuple[RetrievedChunk, ...]:
        """Return `chunks` ordered by descending score."""
        return tuple(sorted(chunks, key=lambda chunk: chunk.score, reverse=True))


class AuthorityReranker:
    """Blends retrieval score with graph PageRank authority."""

    def __init__(
        self,
        authority_weight: float = 0.3,
        authority: dict[str, float] | None = None,
    ) -> None:
        self._weight = authority_weight
        self._authority = authority or {}

    def rerank(
        self, query: str, chunks: tuple[RetrievedChunk, ...]
    ) -> tuple[RetrievedChunk, ...]:
        """Return `chunks` ordered by a blend of retrieval score and authority."""

        def blended(chunk: RetrievedChunk) -> float:
            authority = self._authority.get(chunk.chunk_id, 0.0)
            return (1.0 - self._weight) * chunk.score + self._weight * authority

        return tuple(sorted(chunks, key=blended, reverse=True))
```

```python
"""Per-role model configuration and the provider adapter interface.

Models are chosen per pipeline role, not globally. The generator does grounded
legal reasoning and warrants a frontier model; translation and classification do
not, and paying frontier prices for them is waste. Per-language overrides exist
because Indic-specialist models often beat general models on Indian languages.

No call site names a model directly — every one resolves through the registry.
"""

from enum import Enum
from typing import Any, Protocol

from pydantic import BaseModel, ConfigDict

from openlaw.config import Settings


class ModelRole(Enum):
    """A role in the answer pipeline, each independently configurable."""

    GENERATOR = "generator"
    TRANSLATOR = "translator"
    CLASSIFIER = "classifier"


DEFAULT_MODELS: dict[ModelRole, str] = {
    ModelRole.GENERATOR: "claude-opus-5",
    ModelRole.TRANSLATOR: "claude-haiku-4-5",
    ModelRole.CLASSIFIER: "claude-haiku-4-5",
}


class Completion(BaseModel):
    """One model response."""

    model_config = ConfigDict(frozen=True)

    text: str
    stop_reason: str = "end_turn"
    raw: dict[str, Any] = {}


class LLMAdapter(Protocol):
    """A provider-agnostic completion interface."""

    def complete(
        self,
        model: str,
        system: str,
        messages: list[dict[str, Any]],
        output_schema: dict[str, Any] | None,
        max_tokens: int,
    ) -> Completion:
        """Return a completion from `model`."""
        ...


class ModelRegistry:
    """Resolves a model name for a pipeline role, optionally per language."""

    def __init__(
        self,
        models: dict[ModelRole, str] | None = None,
        language_overrides: dict[tuple[ModelRole, str], str] | None = None,
    ) -> None:
        self._models = dict(models or {})
        self._overrides = dict(language_overrides or {})

    def for_role(self, role: ModelRole, language: str | None = None) -> str:
        """Return the model configured for `role`, honouring `language` overrides."""
        if language:
            override = self._overrides.get((role, language))
            if override:
                return override
        return self._models.get(role) or DEFAULT_MODELS[role]

    @classmethod
    def from_settings(cls, settings: Settings) -> "ModelRegistry":
        """Build a registry from environment-driven settings."""
        return cls(
            {
                ModelRole.GENERATOR: settings.model_generator,
                ModelRole.TRANSLATOR: settings.model_translator,
                ModelRole.CLASSIFIER: settings.model_classifier,
            }
        )


class StubAdapter:
    """A recording `LLMAdapter` for tests — never touches a network."""

    def __init__(self, responses: list[str]) -> None:
        self._responses = list(responses)
        self.calls: list[dict[str, Any]] = []

    def complete(
        self,
        model: str,
        system: str,
        messages: list[dict[str, Any]],
        output_schema: dict[str, Any] | None,
        max_tokens: int,
    ) -> Completion:
        """Return the next queued response, recording the call."""
        self.calls.append(
            {
                "model": model,
                "system": system,
                "messages": messages,
                "output_schema": output_schema,
                "max_tokens": max_tokens,
            }
        )
        if not self._responses:
            raise RuntimeError("StubAdapter exhausted: no queued responses remain")
        return Completion(text=self._responses.pop(0))
```

```python
"""Anthropic implementation of the LLM adapter.

Details that are load-bearing on current models:

- Structured outputs use `output_config={"format": ...}`, not the deprecated
  `output_format`.
- Thinking is `{"type": "adaptive"}`; `budget_tokens` is rejected on Opus 5.
- Assistant prefill returns a 400 and is not used — shape comes from the schema.
- Server-side refusal fallbacks are enabled by default on Opus 5, and
  `stop_reason == "refusal"` is checked before reading content.
- Prompt caching: the system prompt carries the cache breakpoint; per-turn
  retrieved chunks live in `messages` after it, so they never invalidate it.
"""

from typing import Any

from anthropic import Anthropic

from openlaw.answers.models import Completion

FALLBACK_BETA = "server-side-fallback-2026-07-01"


class AnthropicAdapter:
    """An `LLMAdapter` backed by the Anthropic API."""

    def __init__(self, api_key: str) -> None:
        self._client = Anthropic(api_key=api_key)

    def complete(
        self,
        model: str,
        system: str,
        messages: list[dict[str, Any]],
        output_schema: dict[str, Any] | None,
        max_tokens: int,
    ) -> Completion:
        """Return a completion, with caching, adaptive thinking and fallbacks."""
        request: dict[str, Any] = {
            "model": model,
            "max_tokens": max_tokens,
            "system": [
                {
                    "type": "text",
                    "text": system,
                    "cache_control": {"type": "ephemeral"},
                }
            ],
            "messages": messages,
            "thinking": {"type": "adaptive"},
            "betas": [FALLBACK_BETA],
            "fallbacks": "default",
        }
        if output_schema is not None:
            request["output_config"] = {
                "format": {"type": "json_schema", "schema": output_schema}
            }

        response = self._client.beta.messages.create(**request)

        if response.stop_reason == "refusal":
            return Completion(text="", stop_reason="refusal")

        text = "".join(
            block.text
            for block in response.content
            if getattr(block, "type", "") == "text"
        )
        return Completion(text=text, stop_reason=response.stop_reason or "end_turn")
```

```python
"""The structured answer contract.

The generator returns JSON — a list of claims, each carrying the `chunk_id`s that
support it — rather than prose with inline citations. This makes validation a set
membership check instead of a parsing problem: unsupported claims can be dropped
individually, and no regex can mis-read a citation.
"""

import json
from typing import Any

from pydantic import BaseModel, ConfigDict, Field, ValidationError


class Claim(BaseModel):
    """One factual legal assertion and the chunks that support it."""

    model_config = ConfigDict(frozen=True)

    text: str = Field(min_length=1)
    chunk_ids: tuple[str, ...] = Field(min_length=1)


class DraftAnswer(BaseModel):
    """The model's unvalidated response."""

    model_config = ConfigDict(frozen=True)

    summary: str
    claims: tuple[Claim, ...] = ()
    sufficient: bool

    @classmethod
    def from_json(cls, payload: str) -> "DraftAnswer":
        """Parse `payload`, raising ValueError when malformed or invalid."""
        try:
            data = json.loads(payload)
        except (TypeError, json.JSONDecodeError) as error:
            raise ValueError(f"generator returned malformed JSON: {error}") from error
        try:
            return cls.model_validate(data)
        except ValidationError as error:
            raise ValueError(f"generator JSON failed validation: {error}") from error


ANSWER_JSON_SCHEMA: dict[str, Any] = {
    "type": "object",
    "properties": {
        "summary": {
            "type": "string",
            "description": "Plain-language answer for a non-lawyer.",
        },
        "claims": {
            "type": "array",
            "description": "Each legal assertion with its supporting chunk ids.",
            "items": {
                "type": "object",
                "properties": {
                    "text": {"type": "string"},
                    "chunk_ids": {
                        "type": "array",
                        "items": {"type": "string"},
                        "minItems": 1,
                    },
                },
                "required": ["text", "chunk_ids"],
                "additionalProperties": False,
            },
        },
        "sufficient": {
            "type": "boolean",
            "description": "False when the provided sources cannot support an answer.",
        },
    },
    "required": ["summary", "claims", "sufficient"],
    "additionalProperties": False,
}
```

```python
"""System prompt and per-turn context assembly.

Render order is `tools -> system -> messages`, and any byte change invalidates
everything after it. The system prompt is therefore frozen and carries the cache
breakpoint; retrieved chunks — different every turn — go into `messages` after it
and carry no `cache_control`.
"""

from typing import Any

from openlaw.retrieval.context import RetrievalContext

SYSTEM_PROMPT = """\
You are OpenLaw.in, a free legal-information assistant for people in India.

You answer ordinary people, not lawyers. Write in plain language a person with no \
legal training can act on. Avoid Latin, avoid jargon, and explain any legal term \
you must use.

You will be given a question and a set of source excerpts from Indian legislation \
and court judgments. Each excerpt is labelled with a chunk_id.

Rules you must follow exactly:

1. Every legal assertion you make must be supported by at least one chunk_id from \
the excerpts provided in this turn. Never cite a chunk_id that is not listed.
2. Never rely on legal knowledge that is not in the provided excerpts. If you know \
something the excerpts do not support, leave it out.
3. If the excerpts do not let you answer, set "sufficient" to false, say briefly \
what is missing, and return no claims.
4. Do not state what the person should do in their specific case as though it were \
certain. Explain what the law says and what options generally exist.
5. This is legal information, not legal advice. Do not present yourself as a lawyer.
6. Never ask for identifying details such as names, case numbers, or Aadhaar numbers.

Return only the structured JSON object requested."""


def build_context_message(context: RetrievalContext) -> dict[str, Any]:
    """Return the per-turn user message carrying the question and its sources.

    Deliberately carries no `cache_control` — retrieved chunks differ every turn,
    so caching them would produce a 0% hit rate and cost more than not caching.
    """
    lines: list[str] = [f"Question: {context.query}", "", "Source excerpts:"]

    for chunk in context.chunks:
        heading = chunk.title or chunk.court_code or chunk.kind.value
        lines.append("")
        lines.append(f"[chunk_id: {chunk.chunk_id}] ({heading})")
        if chunk.headnote:
            lines.append(f"Headnote: {chunk.headnote}")
        lines.append(chunk.text)

    if not context.chunks:
        lines.append("")
        lines.append("(no source excerpts were retrieved)")

    return {"role": "user", "content": [{"type": "text", "text": "\n".join(lines)}]}
```

```python
"""The citation validator — the core of the product.

Every chunk_id a claim cites must be a member of the retrieval set for that turn.
This is set membership, not parsing: there is no regex to mis-read a citation and
no second model call to pay for. That is what makes "verified" compatible with
"free".

Partial grounding is treated as no grounding. A claim mixing one real citation
with one invented one is dropped whole, because the invented part is exactly the
assertion a reader cannot check.
"""

from pydantic import BaseModel, ConfigDict

from openlaw.answers.schema import Claim, DraftAnswer
from openlaw.retrieval.context import RetrievalContext


class Source(BaseModel):
    """A citation rendered to the user, always with a government URL."""

    model_config = ConfigDict(frozen=True)

    chunk_id: str
    source_url: str
    title: str | None = None


class DroppedClaim(BaseModel):
    """A claim removed because it cited chunks that were not retrieved."""

    model_config = ConfigDict(frozen=True)

    text: str
    unresolvable_chunk_ids: tuple[str, ...]


class ValidatedAnswer(BaseModel):
    """The answer after validation — only verifiable claims survive."""

    model_config = ConfigDict(frozen=True)

    summary: str
    claims: tuple[Claim, ...] = ()
    sources: tuple[Source, ...] = ()
    dropped: tuple[DroppedClaim, ...] = ()
    is_answerable: bool = False


def validate_answer(draft: DraftAnswer, context: RetrievalContext) -> ValidatedAnswer:
    """Drop every claim citing a chunk absent from `context`.

    Returns a new `ValidatedAnswer`; `draft` is not modified.
    """
    permitted = context.chunk_ids
    kept: list[Claim] = []
    dropped: list[DroppedClaim] = []

    for claim in draft.claims:
        unresolvable = tuple(
            chunk_id for chunk_id in claim.chunk_ids if chunk_id not in permitted
        )
        if unresolvable:
            dropped.append(
                DroppedClaim(text=claim.text, unresolvable_chunk_ids=unresolvable)
            )
            continue
        kept.append(claim)

    sources: list[Source] = []
    seen: set[str] = set()
    for claim in kept:
        for chunk_id in claim.chunk_ids:
            if chunk_id in seen:
                continue
            chunk = context.by_id(chunk_id)
            if chunk is None:
                continue
            seen.add(chunk_id)
            sources.append(
                Source(
                    chunk_id=chunk.chunk_id,
                    source_url=chunk.source_url,
                    title=chunk.title,
                )
            )

    return ValidatedAnswer(
        summary=draft.summary,
        claims=tuple(kept),
        sources=tuple(sources),
        dropped=tuple(dropped),
        is_answerable=bool(kept) and draft.sufficient,
    )
```

```python
"""Escalation, crisis routing, and hallucination logging.

Routing someone to a human is a success state. Every answer ends with a route to
free legal aid, and questions signalling danger get helpline numbers ahead of any
legal analysis — these surface constantly in legal-aid queries, and a statutory
explanation is the wrong first response.

Every dropped citation is logged. That log is both a safety metric and a labelled
evaluation dataset produced free by production traffic.
"""

import json
import re
from datetime import UTC, datetime
from enum import Enum
from pathlib import Path

from pydantic import BaseModel, ConfigDict

from openlaw.answers.validate import ValidatedAnswer
from openlaw.retrieval.context import RetrievalContext

NALSA_HELPLINE = "15100"


class CrisisKind(Enum):
    """Categories requiring an immediate helpline rather than legal analysis."""

    DOMESTIC_VIOLENCE = "domestic_violence"
    CUSTODIAL_ABUSE = "custodial_abuse"
    TRAFFICKING = "trafficking"
    SELF_HARM = "self_harm"


CRISIS_PATTERNS: dict[CrisisKind, tuple[str, ...]] = {
    CrisisKind.SELF_HARM: (
        r"\bend my life\b", r"\bkill myself\b", r"\bsuicide\b",
        r"\bno reason to live\b",
    ),
    CrisisKind.TRAFFICKING: (
        r"\btrafficked\b", r"\btrafficking\b", r"\bsold into\b",
        r"\bforced (?:labour|labor|prostitution)\b",
    ),
    CrisisKind.CUSTODIAL_ABUSE: (
        r"\bpolice\s+(?:beat|beating|tortured|torture)\b",
        r"\bin (?:the )?lockup\b",
        r"\bcustodial (?:death|torture|violence)\b",
    ),
    CrisisKind.DOMESTIC_VIOLENCE: (
        r"\b(?:husband|wife|in-laws|partner)\s+(?:beats?|beating|hits?|hitting)\b",
        r"\bdomestic violence\b", r"\bdowry harassment\b", r"\bbeats me\b",
    ),
}

_CRISIS_RESPONSES: dict[CrisisKind, str] = {
    CrisisKind.SELF_HARM: (
        "If you are thinking about harming yourself, please talk to someone now. "
        "Tele-MANAS is free and available 24 hours on 14416. "
        "You do not have to face this alone."
    ),
    CrisisKind.TRAFFICKING: (
        "If someone is in immediate danger, call 112. "
        "The helpline is 1098 for children and 181 for women. "
        "Both are free and available at any hour."
    ),
    CrisisKind.CUSTODIAL_ABUSE: (
        "If someone is being harmed in custody, this is urgent. "
        "Call 112, and contact the National Human Rights Commission on 14433. "
        "A free legal aid lawyer can be requested immediately on 15100."
    ),
    CrisisKind.DOMESTIC_VIOLENCE: (
        "If you are in danger right now, call 112. "
        "The women's helpline is 181, and the police women's helpline is 1091. "
        "Both are free and available 24 hours."
    ),
}

# Severity order — the most urgent category wins when a message matches several.
_SEVERITY_ORDER: tuple[CrisisKind, ...] = (
    CrisisKind.SELF_HARM,
    CrisisKind.TRAFFICKING,
    CrisisKind.CUSTODIAL_ABUSE,
    CrisisKind.DOMESTIC_VIOLENCE,
)

_COMPILED: dict[CrisisKind, tuple[re.Pattern[str], ...]] = {
    kind: tuple(re.compile(pattern, re.IGNORECASE) for pattern in patterns)
    for kind, patterns in CRISIS_PATTERNS.items()
}


def detect_crisis(text: str) -> CrisisKind | None:
    """Return the crisis category `text` signals, or None."""
    if not text:
        return None
    for kind in _SEVERITY_ORDER:
        if any(pattern.search(text) for pattern in _COMPILED[kind]):
            return kind
    return None


def crisis_response(kind: CrisisKind) -> str:
    """Return the helpline-first response for `kind`."""
    return _CRISIS_RESPONSES[kind]


def escalation_footer(state: str | None = None) -> str:
    """Return the free-legal-aid routing appended to every answer."""
    authority = (
        f"the {state} State Legal Services Authority"
        if state
        else "your District Legal Services Authority"
    )
    return (
        "This is legal information, not legal advice, and it cannot replace a "
        "lawyer who knows your case.\n\n"
        f"You may be entitled to a free lawyer. Contact {authority}, or call the "
        f"NALSA helpline on {NALSA_HELPLINE}. Around 80% of people in India "
        "qualify for free legal aid."
    )


class HallucinationEvent(BaseModel):
    """A record of citations the validator refused to render."""

    model_config = ConfigDict(frozen=True)

    question: str
    dropped_chunk_ids: tuple[str, ...]
    retrieved_chunk_ids: tuple[str, ...]
    claim_text: str
    timestamp: str


def build_hallucination_events(
    question: str, answer: ValidatedAnswer, context: RetrievalContext
) -> tuple[HallucinationEvent, ...]:
    """Return one event per dropped claim. Empty when nothing was dropped."""
    if not answer.dropped:
        return ()
    now = datetime.now(UTC).isoformat()
    retrieved = tuple(sorted(context.chunk_ids))
    return tuple(
        HallucinationEvent(
            question=question,
            dropped_chunk_ids=dropped.unresolvable_chunk_ids,
            retrieved_chunk_ids=retrieved,
            claim_text=dropped.text,
            timestamp=now,
        )
        for dropped in answer.dropped
    )


def append_events(events: tuple[HallucinationEvent, ...], path: Path) -> int:
    """Append `events` to the JSONL log at `path`. Returns the number written."""
    if not events:
        return 0
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a", encoding="utf-8") as handle:
        for event in events:
            handle.write(json.dumps(event.model_dump()) + "\n")
    return len(events)
```

```python
from openlaw.answers.models import LLMAdapter, ModelRegistry, ModelRole
from openlaw.answers.prompts import SYSTEM_PROMPT, build_context_message
from openlaw.answers.schema import ANSWER_JSON_SCHEMA, DraftAnswer
from openlaw.answers.validate import ValidatedAnswer, validate_answer
from openlaw.retrieval.context import RetrievalContext

MAX_ANSWER_TOKENS = 4096
_UNANSWERABLE_SUMMARY = (
    "I could not find enough in the law I have access to answer this reliably."
)


class AnswerResult(BaseModel):
    """Everything one turn produces."""

    model_config = ConfigDict(frozen=True)

    answer: ValidatedAnswer
    crisis: CrisisKind | None = None
    footer: str = ""
    events: tuple[HallucinationEvent, ...] = ()


def generate_answer(
    question: str,
    context: RetrievalContext,
    adapter: LLMAdapter,
    registry: ModelRegistry,
    state: str | None = None,
) -> AnswerResult:
    """Generate, validate and package one answer.

    A malformed or refused generation yields an unanswerable result rather than an
    unvalidated one.
    """
    completion = adapter.complete(
        model=registry.for_role(ModelRole.GENERATOR),
        system=SYSTEM_PROMPT,
        messages=[build_context_message(context)],
        output_schema=ANSWER_JSON_SCHEMA,
        max_tokens=MAX_ANSWER_TOKENS,
    )

    footer = escalation_footer(state)
    crisis = detect_crisis(question)

    if completion.stop_reason == "refusal" or not completion.text.strip():
        return AnswerResult(
            answer=ValidatedAnswer(summary=_UNANSWERABLE_SUMMARY, is_answerable=False),
            crisis=crisis,
            footer=footer,
        )

    try:
        draft = DraftAnswer.from_json(completion.text)
    except ValueError:
        return AnswerResult(
            answer=ValidatedAnswer(summary=_UNANSWERABLE_SUMMARY, is_answerable=False),
            crisis=crisis,
            footer=footer,
        )

    validated = validate_answer(draft, context)
    return AnswerResult(
        answer=validated,
        crisis=crisis,
        footer=footer,
        events=build_hallucination_events(question, validated, context),
    )
```

```python
from pydantic import BaseModel, ConfigDict, Field

class EvalQuestion(BaseModel):
    """One evaluation question with its known-correct sources."""

    model_config = ConfigDict(frozen=True)

    question: str = Field(min_length=1)
    gold_chunk_ids: tuple[str, ...] = Field(min_length=1)
    language: str = "en"
    category: str = "general"


def load_eval_set(path: Path) -> tuple[EvalQuestion, ...]:
    """Load evaluation questions from the JSONL file at `path`."""
    if not path.exists():
        raise FileNotFoundError(f"evaluation set not found at {path}")

    questions: list[EvalQuestion] = []
    with path.open(encoding="utf-8") as handle:
        for line in handle:
            stripped = line.strip()
            if not stripped:
                continue
            questions.append(EvalQuestion.model_validate(json.loads(stripped)))
    return tuple(questions)
```

```python
"""Evaluation metrics and the release gate.

Two thresholds from the spec: retrieval recall@10 at or above 0.85, and zero
unverifiable citations. The second is not a percentage — one fabricated citation
that reached a user is a product failure.
"""

from collections.abc import Sequence
from dataclasses import dataclass

RECALL_THRESHOLD = 0.85
RECALL_K = 10


@dataclass(frozen=True)
class QuestionResult:
    """The outcome of evaluating one question."""

    recall: float
    unverifiable_citations: int


@dataclass(frozen=True)
class EvalReport:
    """Aggregate evaluation outcome."""

    questions: int
    mean_recall: float
    unverifiable_citations: int

    @property
    def passes(self) -> bool:
        """True when both spec gates are met."""
        return (
            self.questions > 0
            and self.mean_recall >= RECALL_THRESHOLD
            and self.unverifiable_citations == 0
        )


def recall_at_k(
    retrieved: tuple[str, ...], gold: tuple[str, ...], k: int = RECALL_K
) -> float:
    """Return the fraction of `gold` chunks present in the first `k` `retrieved`."""
    if not gold:
        return 0.0
    top = set(retrieved[:k])
    return sum(1 for chunk_id in gold if chunk_id in top) / len(gold)


def evaluate(results: Sequence[QuestionResult]) -> EvalReport:
    """Aggregate per-question results into a report."""
    if not results:
        return EvalReport(questions=0, mean_recall=0.0, unverifiable_citations=0)
    return EvalReport(
        questions=len(results),
        mean_recall=sum(result.recall for result in results) / len(results),
        unverifiable_citations=sum(
            result.unverifiable_citations for result in results
        ),
    )
```

```python
"""Run the evaluation gate: recall@10 >= 0.85 and zero unverifiable citations.

Requires a completed evaluation set with gold_chunk_ids filled in.
Run: python scripts/run_eval.py
"""

import sys
from pathlib import Path

import httpx

from openlaw.answers.anthropic_client import AnthropicAdapter
from openlaw.answers.generate import generate_answer
from openlaw.answers.models import ModelRegistry
from openlaw.config import get_settings
from openlaw.evaluation.dataset import MINIMUM_QUESTIONS, load_eval_set
from openlaw.evaluation.metrics import QuestionResult, evaluate, recall_at_k
from openlaw.retrieval.context import RetrievalContext
from openlaw.retrieval.query import VoyageQueryEmbedder
from openlaw.retrieval.search import search

EVAL_PATH = Path("data/eval/citizen_questions.jsonl")


def main() -> int:
    settings = get_settings()
    if not settings.voyage_api_key or not settings.anthropic_api_key:
        print("[Eval] FAIL: OPENLAW_VOYAGE_API_KEY and OPENLAW_ANTHROPIC_API_KEY needed")
        return 1

    questions = load_eval_set(EVAL_PATH)
    print(f"[Eval] loaded {len(questions):,} questions")
    if len(questions) < MINIMUM_QUESTIONS:
        print(f"[Eval] WARNING: below the {MINIMUM_QUESTIONS}-question minimum")

    embedder = VoyageQueryEmbedder(settings.voyage_api_key)
    adapter = AnthropicAdapter(settings.anthropic_api_key)
    registry = ModelRegistry.from_settings(settings)

    results: list[QuestionResult] = []
    with httpx.Client(timeout=60) as client:
        for question in questions:
            vector = embedder.embed_query(question.question)
            chunks = search(client, settings.qdrant_url, vector, limit=10)
            context = RetrievalContext(query=question.question, chunks=chunks)

            recall = recall_at_k(
                tuple(chunk.chunk_id for chunk in chunks), question.gold_chunk_ids
            )
            outcome = generate_answer(question.question, context, adapter, registry)
            unverifiable = sum(
                len(dropped.unresolvable_chunk_ids)
                for dropped in outcome.answer.dropped
            )
            results.append(
                QuestionResult(recall=recall, unverifiable_citations=unverifiable)
            )

    report = evaluate(results)
    print(f"[Eval] questions              : {report.questions:,}")
    print(f"[Eval] mean recall@10         : {report.mean_recall:.3f} (need >= 0.850)")
    print(f"[Eval] unverifiable citations : {report.unverifiable_citations} (need 0)")

    if not report.passes:
        print("[Eval] FAIL")
        return 1
    print("[Eval] PASS")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
