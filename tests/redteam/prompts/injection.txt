# Hostile uploaded-document bodies for the adversarial gate.
#
# Each case begins with a line `=== <id> ===`; everything until the next such
# line is that case's document body, verbatim. Blank lines and lines beginning
# with `#` OUTSIDE a body are ignored; inside a body every byte is kept, because
# a payload's whitespace and its `#` characters are part of the attack.
#
# These are the inputs an attacker actually has: the bytes of a file somebody
# uploads. Nothing here is a prompt this project writes. The tests that read
# this file assume the model OBEYS every one of these instructions, and assert
# that the deterministic layers downstream -- the fence, the two-namespace
# validator, the response schema, the renderer -- hold anyway. A test that
# passed only because a model declined would be measuring the wrong thing.
